# Code of Conduct

We want Beyrix to be a welcoming technical community for users and contributors.

Be respectful, constructive, patient with beginners, and open to evidence-based disagreement. Critique code and ideas rather than attacking people. Harassment, hate speech, threats, stalking and publication of private information are not tolerated.

This applies to GitHub issues, pull requests, discussions and other spaces represented as official Beyrix community channels.

If you see a problem, report it privately to the project maintainer through an available private GitHub channel. Do not publish sensitive personal information in an issue. Maintainers may edit or remove content, issue warnings, restrict participation or block accounts when necessary.

We will aim to review reports fairly, protect reporter privacy where reasonably possible and avoid retaliation.
