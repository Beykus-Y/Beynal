# Screenshots

These files are real screen captures of Beyrix, not generated mock-ups.

- Environment: Fedora Linux 44, Niri 26.04 on Wayland, 1920×1080 output at scale 1.25, AMD Radeon integrated graphics (Mesa 26.1.8).
- `bash.png` — `beyrix --help` in a Bash session using the OpenGL backend and the `signature` theme.
- `opencode.png` — OpenCode 2.4 TUI running inside Beyrix.
- `editor.png` — the built-in editor opened with `beyrix edit demo.rs`.
- `demo.gif` — live theme switching from `beyrix theme set developer` back to `beyrix theme set signature`.

The captures use a temporary demo home directory; no tokens, credentials or personal paths are shown. Do not add screenshots that contain secrets or private data. When replacing an image, use a real Beyrix capture and update this file.
