# Beyrix v0.1.0-alpha.2

Beyrix's second alpha introduces BEdit's project workspace and improves text rendering on Wayland displays with fractional scaling.

## BEdit

- Run the new BEdit command with a directory and one or more files to open a project with an Explorer sidebar and file tabs. BEdit also has its own desktop launcher.
- Launch BEdit from an existing Beyrix Bash session to open the editor in the same window. Use the standalone option to open a separate window.
- Navigate project files with Quick Open, highlight supported syntax, and find and replace text.
- Save atomically, confirm before discarding unsaved work, and detect external changes before overwriting a file.
- Preserve UTF-8 BOM, CRLF line endings, permissions, POSIX ACLs and extended attributes on supported filesystems.

## Font rendering and HiDPI

- Derive cell dimensions and the baseline from the selected font at its physical size. Place glyph bitmaps on integer pixel boundaries, including at fractional scales.
- Use the same physical grid for Beyrix and BEdit, including terminal sizing, cursor placement, selection and mouse hit testing. OpenGL and software render the same scene.
- Render the software framebuffer at native physical resolution and keep its Wayland viewport in logical coordinates.
- Submit pending glyph draws before reusing a full atlas. Keep the EGL background opaque when compositing antialiased text.
- Show a replacement character when none of the loaded fonts contains a glyph.

## Performance

Local measurements on Fedora 44 with Niri 26.04, AMD Radeon graphics and 125% scaling recorded the median time for a child process to write 20,000 lines to the PTY across three runs.

| Backend | Before | After |
| --- | ---: | ---: |
| OpenGL | 96.3 ms | 81.5 ms |
| Software | 87.9 ms | 83.5 ms |

These figures measure PTY write time. Frame rate and render latency were outside that measurement.

## Installation

The Linux x86_64 archive includes Beyrix, BEdit, the installer, documentation, the license and a manifest of file checksums. Verify the archive against the published SHA-256 checksum. Fedora 44 and 45 packages are built for x86_64 in the existing [beykus-y/beyrix COPR project](https://copr.fedorainfracloud.org/coprs/beykus-y/beyrix/). An existing COPR installation can upgrade through DNF once the new package is available.

## Known limitations

- Linux x86_64 and Wayland only. Beyrix remains alpha-quality software.
- Font fallback coverage is limited. Beyrix currently uses fontdue and has no FreeType or font hinting support.
- BEdit has no LSP integration. Syntax highlighting works line by line without multiline context.
