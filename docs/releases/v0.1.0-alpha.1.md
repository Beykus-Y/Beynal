# Beyrix v0.1.0-alpha.1

**The first public alpha of Beyrix**, an experimental Rust terminal emulator for Linux/Wayland.

This is a pre-release. It is intended for early users and contributors who want to test a native Wayland terminal with OpenGL rendering, customizable layouts and TUI support. Expect rough edges.

![Beyrix running Bash](https://raw.githubusercontent.com/Beykus-Y/Beyrix/main/docs/screenshots/bash.png)

## What is included

- Native Wayland window (`xdg-shell`) with fractional-scaling support through `wp_fractional_scale_v1` and `wp_viewporter` when available.
- OpenGL ES 2.0 rendering through EGL, plus a CPU/`wl_shm` software renderer. `auto` uses OpenGL only for real hardware contexts and falls back to software on llvmpipe/softpipe/swrast or context failure.
- PTY-backed interactive Bash.
- ANSI/VT handling through `vte`: alternate screen, cursor save/restore, 16/256/truecolor SGR, reverse video, bracketed paste, cursor shapes and terminal status reports.
- Scrollback with configurable limits and wheel/Shift+PageUp/PageDown navigation.
- Mouse selection, double-click word selection, triple-click logical-line selection, drag scrolling and Wayland clipboard integration.
- SGR mouse reporting for TUI applications, including modifiers, motion and wheel events.
- Three cursor layouts: `as-is`, `bottom` and `bottom-input`.
- Built-in editor (`beyrix edit FILE`) with undo/redo, clipboard, UTF-8/BOM/CRLF handling, atomic saves, permission preservation and conflict warnings.
- Built-in `minimal`, `developer` and `signature` themes with Git-aware Bash prompts and live theme updates through a local control socket.
- Customizable font size, padding, colors, cursor and scrolling through TOML.
- CLI commands for theme, layout, renderer, GPU diagnostics, editing and `--pty`.
- MPL-2.0 source code.

## Supported platform and requirements

- **Linux x86_64** with a working Wayland session. The official archive is built on Ubuntu 24.04 and requires glibc 2.39 or newer (for example Ubuntu 24.04+, Fedora 40+, Debian 13+).
- A compositor providing `xdg-shell`, `wl_shm`, `wl_seat` and `wl_data_device_manager`. Tested on Niri 26.04; other standard Wayland compositors are expected to work but were not all verified.
- `/bin/bash`, `libwayland-client`, `libxkbcommon`, fontconfig (`fc-match`) and at least one monospace font.
- Optional: `libEGL` and a working OpenGL ES driver for hardware rendering. Without them Beyrix uses the software renderer.
- The binary is dynamically linked against the system libc and `libxkbcommon`; Wayland and EGL are loaded at runtime. It is **not** a fully static or universal binary.
- Windows, macOS, X11 and ARM64 are **not** supported by this release.

## Installation

```sh
VERSION=v0.1.0-alpha.1
BASE="https://github.com/Beykus-Y/Beyrix/releases/download/$VERSION"

curl -LO "$BASE/beyrix-$VERSION-linux-x86_64.tar.gz"
curl -LO "$BASE/SHA256SUMS"
sha256sum -c SHA256SUMS --ignore-missing

tar -xzf "beyrix-$VERSION-linux-x86_64.tar.gz"
cd "beyrix-$VERSION-linux-x86_64"
./install.sh
```

`install.sh` installs to `~/.local/bin` by default. Use `PREFIX=/usr/local ./install.sh` for a system-wide install. Make sure the install directory is in `PATH`, then run:

```sh
beyrix
```

The archive also contains `LICENSE`, `README.md`, the English and Russian configuration guides, `docs/ARCHITECTURE.md`, and `BUILD-INFO.txt` with the source commit and build toolchain. The release also ships `SHA256SUMS` for verification.

## Known limitations

- Alpha-quality terminal compatibility. Beyrix is not a complete xterm/VT implementation; some programs or escape sequences may not work. Please report a minimal reproducer.
- Wayland/Linux x86_64 only. There is no X11 backend, Windows/macOS port or ARM64 build.
- No Vulkan renderer. Vulkan devices are detected for diagnostics only; the `vulkan` option falls back to software.
- One terminal session per window; no tabs or split panes.
- Wayland keyboard autorepeat is not implemented in the graphical window.
- The editor supports one file at a time, without tabs, syntax highlighting or LSP.
- Asynchronous output may overwrite the pinned input line in the `bottom-input` layout.
- Hardware acceleration depends on the compositor, EGL and driver. The software renderer is the guaranteed fallback and may use more CPU on large windows.
- Beyrix is not security-audited. It runs shell programs and handles terminal escape sequences and clipboard data; treat it as experimental software.

## Verification

The release workflow builds from the tagged commit with `Cargo.lock`, runs `cargo fmt --all -- --check`, clippy with `-D warnings` on all targets and features, all tests, and a release build before packaging. The archive is published only if those steps pass. SHA-256 checksums are attached to the release and verified after uploading the workflow artifact.
