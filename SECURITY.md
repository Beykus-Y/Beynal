# Security Policy

Beyrix is experimental (0.1.x) and does not yet have a documented stable-support period.

## Reporting a vulnerability

Please **do not open a public issue** for a vulnerability involving potential code execution, terminal escape handling, clipboard data leakage, filesystem access, PTY/session isolation or similar sensitive behavior.

If GitHub's **Report a vulnerability / Private vulnerability reporting** option is enabled for this repository, use it under the repository's Security tab. Otherwise, reach out to the repository owner through an available private channel and request a secure reporting route before sharing exploit details.

Please provide the affected version or commit, environment, impact and a minimal reproducer when safe to do so. We cannot guarantee a fixed response time but will prioritize credible security reports.

Public compatibility problems without security implications should use the regular issue tracker.
